# EatMeFirst（先吃我）

Your fridge's eat-me-first list — before it rots.

Mobile-first PWA scaffold (Prompt 1): Next.js App Router + TypeScript + Tailwind, bottom tabs, and web app manifest. No backend or auth in v1.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Inventory: `/`
- Add: `/add`
- Eat First: `/today`

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
- `npm run lint` — ESLint

## Out of scope (v1)

Login, cloud sync, barcode, OCR, recipes, gram-level quantities, multi-user sharing, native push.
